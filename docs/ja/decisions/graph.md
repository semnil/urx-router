# Decisions: the node graph

> English version: [../../en/decisions/graph.md](../../en/decisions/graph.md)

[src/ui/graph.ts](../../../src/ui/graph.ts) が描く盤面について、閉じた判断と、その周りで起きたことを置く。盤面の
仕組みは [architecture.md](../architecture.md) の「ノードグラフの描画制約」「ノードの非表示」
「ぶら下げノード (Ducker・microSD Rec スロット)」「列レイアウト」「ノードラベル」にある。経路トレースと OFF 表示の
統一は、同じ文書の「データモデル」の下にある。この文書は、そこに無い経緯を持つ。下の「操作者」は、この
プロジェクトの作業を指示し、決める人のこと。

## Two gestures on a node

**決定。** ノードのダブルクリックは、ノートの編集。長押しは、経路トレース。経路トレースを、ダブルクリックへは
**戻さない**。

**経緯。** 経路トレースは、最初はダブルクリックにあった。それを長押しへ移し、その後、ダブルクリックをノートの
編集に戻して、2 つを並べた。2 つはぶつからない。2 度押しの判定は、ドラッグの準備より前にあって、そこで戻る。
素早い 2 度目の押下は、長押しのタイマーを張らない。2 度押しは、盤面が自分で判定する (`lastNodeClick`)。
`preventDefault` を呼ぶ `pointerdown` は、`dblclick` のイベントを抑えるため。長押しを待っている間は、
`LONG_PRESS_TOLERANCE` より短い移動を飲み込む。これが無いと、押した時点でドラッグの対象になっているノードが
動き始め、長押しが成り立たない。

## Ducker and state marks

- **ducker のキーソースは、専用の接続の種類 `key` にする。** `source` でも `patch` でもない。狙いは、
  `kind === "source"` の分岐に、決して一致させないこと。その分岐は、接続のときにペアのソースを写し、削除のときに
  相方の分を消す。`source` を使い回すと、「ducker が `channelPairs` に無い」という偶然で、何も起きないだけに
  なっていた。
- **1 つのノードに出す状態は 1 つで、3 つのうちいちばん上のもの。** ノードは、レートで無効・非アクティブ・未確認の
  3 つに、同時に当たることがある。3 つのブロックは、**レートで無効 → ミュート → 未確認** の順の、排他の連なりに
  してある。選択のハイライトの枠のガードも、同じ順。前は、バッジが重なり、下の状態の opacity が、上の状態の
  opacity を上書きすることがあった。
- **「このノードは OFF」を問う述語は、`isNodeInactive` の 1 つ。** ducker は、ON / OFF を `on` ではなく `duckerOn`
  に持つ。述語は、種類で分岐する。CONSOLE も、同じ述語を使う。

## Hiding

**決定。** どのノードも、接続があっても無くても、棚に入れられる。ぶら下げノードの親と子は、1 つの組として
入り、戻る。

**置き換えた前の形。** 前は、接続を持つノードの非表示を断っていた。強制して隠す案は、操作者が却下していた。
これを反転した。端が隠れた配線は、配線を描くときに飛ばすので、宙に浮くものは残らない。接続はプランに残り、
ノードと一緒に戻る。非表示は、表示だけの操作。断るためのゲートと述語は、消した。

## Path trace

トレースが何を光らせるかと、その理由は、architecture.md と
[#607](https://github.com/semnil/urx-router/pull/607) (2026-10-13 マージ) にある。そこで閉じたもの:

- **ducker を通すかどうかは、信号を取り出す位置で決める。** CUE だけの決まりにはしない。最初の決定は
  「CUE だけ外す」だった。別のセッションのレビューで、取り出す位置 (`tapAheadOfDucker`) に置き換えた。実機の
  ブロック図に従う。
- **ミュートした CH への入力の配線は、その CH が、生きた直出しかキーを持つ間だけ、通常の表示にする。**
  却下した案: 常に通常の表示にする。表示を今のままにする。
- **経路の上の、ミュート中のノードは、0.4 の減光を保つ。** 経路の外の 0.3 と見分けにくい。操作者が見た上で、
  受け入れた。却下した案: バッジだけで示す。もう提案しない。
- **96 kHz を超えるレートでの FX 2 への Send は、`isOffSend` が OFF と言う。** 盤面の全体で、そう扱う。トレース
  だけの判定は持たない。
- **`live` の述語は、必ず要る。** この機種では、CH は常に、どのバスにも結線されている。OFF や -∞ の Send まで
  たどると、閉包が盤面の全体になる。

**不具合ではなかった報告。** STEREO バスをトレースすると、ミュートした CH の入力が、明るいまま残った。経路は
正しい。ステレオの入力を CH につなぐと、ペアの相方にも、ソースの接続が張られる。片方の CH をミュートしても、
相方はバスへ送っている。入力 → 相方 → バスは、生きた経路になる。入力が暗くなるのは、ペアの 2 つの CH を
ミュートしたとき。E2E の 2 ケースが、2 つの場合を固定している。製品のコードは変えていない。

## Aligning a STEREO pair and coming back from the shelf

設計は、architecture.md の「ノードの非表示」にある。走らせて見つけたことが 5 つあり、素直に書くと、それぞれ
また起きる。

1. **保存したオフセットは、浮動小数でずれる。** ドラッグは `partner - primary` を捕まえ、別の基点から足し直す。
   動いていないペアが、正準の値から約 1e-13 px 外れる (200,000 サンプルの 4.68%)。位置を完全な一致で判定すると、
   動いていないペアを書き直す。これは、編集のファネルの外からのプランへの書き込みになる。判定は、サブピクセルの
   幅で行う。
2. **`repaintDirtyNodes` は、リンクしたペアのタイを描けない。** タイは、`renderNodes` の中でしか組まれない。
   細かい分岐だけを通る経路では、リンクの状態が変わっても、タイが出なかった。全体の描き直しでは出た。全体の
   反映を頼む条件は、座標が動いたかではなく、**リンクの状態**が動いたか。
3. **書くオフセットを、ノートを避けるために広げない。** Arrange は、列を丸ごと詰め直す。スナップは、2 つの
   ノードしか動かさない。広げたオフセットは、次の行のノードに重なる。2 つの CH が、同じ `translate` になった。
   書く値は、既定のオフセットのままにする。「もうスロットにいるか」の判定は、帯にする。既定のオフセット以上で、
   上のノードの行数以下。
4. **棚は、canvas の下の部分を覆う。ノードが戻るとき、棚は必ず開いている。** 「表示されたか」を graph のホストとの
   交差で判定すると、棚の裏のノードが通る。最小のウィンドウと最大のズームでは、使える領域は y = 556 までで、
   戻したノードは y = 576 から始まっていた。下の端は、棚の上の端で取る。
5. **ぶら下げノードの位置は、親から決まる。画面に入れる対象は、チップが名指した id。** `parentOf(id) ?? id`
   ではない。親を収めると、親が見えるだけになる。チップ・ステータス行・インスペクタが名指したトラックのスロットは、
   画面の外に残る (親は 146〜256、スロットは 846〜956、使える領域は 0〜476)。

## The Rec Point tap's geometry

タップジャックが何で、その配線をどう描くかは、architecture.md の「Rec Point タップジャック」にある。ここには、
コードを読んでも分からない選択を置く。

- **タップは、ノードの中央より左にある** (`TAP_CX`)。中央には、STEREO のリンクの結び目が、下のノードの上に
  来る。
- **当たり判定は小さく、ジャックから取る。** ポートの当たりの半径の円にはしない。ノードの上辺をつかむ操作を
  奪う。**行の間隔からは導かない。** ノードはどこへでもドラッグでき、重なりを止めるものは無い。「間隔に
  収まる」は、「上のノードに乗らない」を意味しない。上へ伸ばした分だけ、上に置かれたノードのドラッグを奪い、
  パンも選択の解除も効かない空白のキャンバスが増える。
- **`ROW_GAP` を 60 から 68 にした。** 60 では、タップの線が、上のノードの下辺の 2px 下を走り、そのノードの
  一部に見えた。代償は、盤面を収める倍率。WQHD の画面で約 5%、幅 1600px で約 10% 下がる。76 は採らなかった。
  盤面が間延びし、ラックの密度が無くなる。整列するときだけ広げる形は取れない。整列の結果は、既定の格子と
  等しいことが求められている ([arrange.spec.ts](../../../e2e/arrange.spec.ts))。
- **書き出しには影響しない。** タップの要素を除いて描いたものと、画素まで同じになった。

## The shelf

非表示にしたノードは、キャンバスの下の棚に、モジュールのレールの色のチップとして並ぶ。ほかの 2 つの置き場は
採らなかった。

- **インスペクタの中の一覧。** ノードや配線を選んでいる間は消える。使いたいときに使えない。
- **ツールバーからのポップオーバー。** 開いている間グラフを覆い、クリックが 1 回増える。
